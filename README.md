# NovaMotto - Creative Agency Theme (Original)

Template original inspire du style creative agency/startup, sans copie 1:1 d'un theme commercial.

## Files
- `index.html`: structure complete
- `style.css`: design system, layout, responsive
- `script.js`: reveal animation on scroll

## Positioning
- Market: agencies, studios, SaaS, freelance creatives
- Look: dark premium, neon accents, typography bold
- Ready for sale on: Gumroad, Etsy, Creative Market (or adaptation for ThemeForest)

## Quick customization
1. Update brand name and sections in `index.html`.
2. Change color tokens in `:root` inside `style.css`.
3. Add portfolio thumbnails and real case studies.
